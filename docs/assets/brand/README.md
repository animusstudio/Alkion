# Alkion README artwork

`alkion-banner.svg` and its PNG export pair the retained 96-column character bust
with outlined Alkion lettering and the exact `by Animus` endorsement. The root
README displays the repository-local PNG for predictable Markdown rendering.
The SVG contains real glyph/letter paths, without an underlying sculpture image.

The supplied artwork and outlined lettering retain the applicable SIL Open Font
License notices in `fonts/`: Space Mono 400 and Space Grotesk 500. Keep these
notices with redistributed outlined assets. The launcher source and regeneration
instructions are in [the app icon directory](../../../app/assets/icon/README.md).
