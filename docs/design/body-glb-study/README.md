## Prepare a private preview

```sh
python3 docs/design/body-glb-study/tools/convert-glb.py \
  --input /private/input/model.glb --regions /private/input/regions.json \
  --out /private/assets
python3 docs/design/body-glb-study/tools/check-source.py \
  --input /private/input/model.glb --regions /private/input/regions.json \
  --assets /private/assets --reproduce
node docs/design/body-glb-study/tools/check-study.mjs

  --assets /private/assets --out /private/preview/body-glb-study
python3 -m http.server 8773 --bind 127.0.0.1 --directory /private/preview
```

Open `http://127.0.0.1:8773/body-glb-study/`. These placeholders are caller-selected paths, not repository assets. Both converter and staging tool reject destinations inside this source checkout. ## Source-patch mapping

The source has six export chunks, all unnamed `mesh`, and one material; these are **not muscle groups**. Its embedded atlas contains labeled muscle patches. The separate private JSON recipe binds an exact `sourceSha256` and authors seeds as `{group, label, uv: [u, v]}` plus an explicit integer `rgbTolerance`. UV coordinates use the atlas's top-left origin. No source-specific seed coordinates, texture, mask or derivative geometry is committed here.

Each seed identifies only its four-connected source-color patch within the selected tolerance. The same RGB elsewhere is not selected. Enclosed source-label text along the patch-color-to-white range is filled within that patch; neighboring muscle colors remain separate. Conflicting patches fail conversion. Unselected tissue, source gaps, uncertain boundaries and unsupported muscles stay neutral. The private diagnostic overlays the selected regions on the source atlas for inspection. This is an authored correspondence to eight aggregate exercise groups, not a claim that the source supplies those canonical IDs or that one muscle implies secondary workload.

The female atlas was inspected independently and a fresh recipe authored against its own source hash. The selected labels cover paired PM, Tr/LD/In/TMa, D, RF/VL/VM, BF/SM, Ga/So, BB and T patches. The recipe preserves source label spellings. Back coverage intentionally excludes ambiguous neutral connective/erector areas. Se and ambiguous neck/posterior islands remain neutral rather than inferring a split; two unlabeled posterior deltoid-like islands also stay neutral pending verified correspondence. These are explicit coverage limitations, not zero workload. TMa/In are an authored back-region grouping, not a physiological measurement. All other unselected labels remain neutral. Each bilateral pair reads the same aggregate value. No finer measurement, side-specific workload or inferred physiology is introduced.

`regions.png` is a nearest-sampled ID atlas, `[null, chest, back, shoulders, quads, hamstrings, calves, biceps, triceps]`. It is sampled by immutable source UVs before yaw; region identity cannot slide as the body rotates. Per-triangle centroid IDs in the binary provide an independently checked mapping receipt. They do not flatten fragment-level boundaries.

“Inspect source mapping” exposes a neutral solid posed surface and an eight-color region overlay with legend. These are explicitly diagnostic modes; diagnostic colors do not represent workload. The default remains character material. Both diagnostics share the same posed female-source geometry and transported normals as the character view; changing modes adds no geometry change.
